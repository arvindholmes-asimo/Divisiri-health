## Project Context

- **Project Name**: Divisiri
- **Purpose**: Independent wellness & innovation website
- **Theme**: Wellness, nutrition, holistic health
- **Status**: Standalone project, inspired by but not connected to parent companies
- **Industry**: Wellness, nutraceuticals, holistic health

## Active Skills

The following skills are relevant to this project:
- hyperframes-cli - HyperFrames composition management
- hyperframes-animation - Animation and motion design
- hyperframes-core - Composition structure and timing
- faceless-explainer - Video explanation generation
- improve-codebase-architecture - Codebase analysis and deepening

## Development Workflow

1. Run `npm run dev` to start the HyperFrames preview server
2. Use `npm run check` to validate the composition
3. Render with `npm run render`
4. Publish with `npm run publish`

## Directory Conventions

- HTML goes in root `index.html`
- CSS in `css/style.css`
- JavaScript in `js/main.js`
- Assets in `images/` or `assets/`
- Configuration in `package.json`, `CLAUDE.md`, `AGENTS.md`

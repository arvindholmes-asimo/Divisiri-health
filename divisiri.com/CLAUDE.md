# Divisiri - Wellness & Innovation

An independent wellness and innovation company focused on improving lives through
better nutritional support and holistic health solutions.

## Project Overview

Divisiri operates independently, drawing inspiration from wellness principles
while maintaining its own identity and operations. The project incorporates
elements from the wellness industry landscape while standing alone as an
independent entity.

## Project Structure

```
/divisiri.com/
  ├── index.html       # Main HTML file with wellness focus
  ├── css/style.css    # Stylesheet with wellness color scheme
  ├── js/main.js       # JavaScript functionality
  ├── package.json     # Project configuration
  └── images/          # Image assets (wellness-themed)
```

## Available Scripts

| Script | Description |
|--------|-------------|
| `dev` | Start development server with HyperFrames preview |
| `check` | Run HyperFrames type checking |
| `render` | Render the HyperFrames composition |
| `publish` | Publish the project |

## Technology Stack

- **HTML5** - Semantic markup with wellness focus
- **CSS3** - Custom properties, gradients, animations with health/organic theme
- **JavaScript** - DOM manipulation, Intersection Observer
- **HyperFrames** - Video/animation framework
- **Google Fonts** - Inter typeface

## Development

To start the development server:

```bash
npm run dev
```

To check for type errors:

```bash
npm run check
```

## Design Inspiration

This project incorporates wellness industry principles including:
- Holistic health approach (physical, mental, spiritual balance)
- Nutritional support and wellness focus
- Professional, trustworthy aesthetic
- Organic color scheme (greens for health, oranges for vitality)

## Customization

- Modify `css/style.css` for styling changes (accent colors can be adjusted)
- Update `js/main.js` for interactive features
- Add new sections to `index.html`
- Replace images in the `images/` directory with wellness photography
